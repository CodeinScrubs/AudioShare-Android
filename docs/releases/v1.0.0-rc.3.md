# AudioShare USB Companion v1.0.0-rc.3

Third public release candidate for the Android USB playback companion.

## Reliability fixes

- Fixes a reproduced watchdog bug where deliberately dropped live-edge audio
  could make a later silent period look permanently stalled.
- Tracks only currently queued and in-flight frames when deciding whether
  AudioTrack is stuck.
- Gives both temporarily missing and stale Bluetooth/wired route reports a
  bounded two-second recovery window while repeatedly requesting the built-in
  speaker.
- Applies the compatibility-performance fallback to the entire AudioTrack
  configuration, including buffer size, start threshold, and initial route.
- Prevents a replacement session from starting until the previous playback
  worker has conclusively terminated.
- Adds a 12-hour wake-lock leak guard while preserving normal screen-off use.

## Diagnostics

- Extends the backward-compatible STATS payload with frames written,
  cumulative playback-head frames, write/head progress ages, play state, and
  actual performance mode.
- Keeps the existing queue, buffer, route, focus, volume, underrun, and drop
  diagnostics.

## User guidance

- Directs ordinary users to the complete portable Windows release instead of
  Android Studio or a source build.
- Adds AI-readable setup instructions and credits Shayan SalehiRad.

The previously recorded Samsung Galaxy A52s audible path remains valid evidence
for the product architecture, but this exact RC3 build still requires the open
screen-off, reconnect-cycle, latency, and two-hour physical-device gates before
stable promotion.
