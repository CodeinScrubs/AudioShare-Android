# AudioShare USB Companion v1.0.0-rc.2

Second public release candidate of the permanently signed native Android USB
receiver.

## Improvements since rc.1

- Prevents the connection watchdog from closing a client accepted exactly at
  the timeout boundary.
- Retries `AudioTrack` creation in compatibility mode when an Android vendor
  rejects low-latency mode.
- Bounds playback-worker shutdown and actively releases a vendor-blocked audio
  track so disconnect cannot hang indefinitely.
- Renews the built-in-speaker route grace period after transient Android audio
  policy changes instead of reusing the startup deadline.
- Detects a pending-audio playback stall when both AudioTrack writes and the
  playback head stop advancing, then reports a bounded error to Windows.
- Records foreground-service start rejection explicitly in Android/ADB
  diagnostics while retaining Windows' bounded handshake timeout for vendors
  that do not propagate an Activity exception through `am start -W`.
- Pins the expected release certificate in the repository and verifies it
  before GitHub publishes an APK.

## Release-candidate limitations

Automated unit, lint, package-identity, and host-integration checks pass. A
ten-minute screen-off run, repeated cable/reconnect cycles, measured latency,
and a two-hour endurance run remain manual gates before stable promotion.

Most users should install the companion through the matching AudioShare Windows
package. The standalone APK is provided for inspection and controlled testing.
