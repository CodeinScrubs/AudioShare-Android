# AudioShare USB Companion v1.0.0-rc.1

First public, permanently signed release candidate of the native Android USB
receiver.

## Included

- Authenticated, nonce-scoped ADB-forwarded audio sessions.
- 48 kHz stereo PCM16 playback through Android `AudioTrack`.
- Enforced built-in-speaker route and media audio-focus handling.
- Bounded live-edge buffering, drop/underrun statistics, and wake-lock cleanup.
- No `INTERNET`, microphone, camera, location, Bluetooth, contacts, or storage
  permission.
- Initial audible hardware validation on a Samsung Galaxy A52s with Android 14.

## Release-candidate limitations

The initial hardware run showed global-system playback with a 10 ms host queue
high-water mark and zero visible host/Android drops. Ten-minute screen-off,
reconnect cycling, measured latency, and two-hour endurance remain manual gates
before stable promotion.

Most users should install the companion through the matching AudioShare Windows
package. The standalone APK is provided for inspection and controlled testing.
